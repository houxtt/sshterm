## 二、sshterm 现状盘点(已完成 23 项测试全绿)

- SSH(密码/密钥)+ keepalive 防断 + 断开原因细分
- Telnet(自动登录 + IAC 协商)
- 串口(全参数 + hex)
- 多标签 + 同 IP 多会话 + 关闭确认
- 会话管理(增删改查/批量删除/持久化)
- SFTP 完整:浏览/上传/文件夹上传/目录打包/进度条/定位当前目录
- 复制粘贴(Xshell 习惯)+ 三层卡死防护(风暴检测/定时器合并/剪贴板静默)
- 刷新自动恢复(标签+终端内容)
- 操作日志 + 全部断开 + 桌面应用化(无窗口/空闲自退)

## 三、差距分析与改进方案(按优先级)

### P0 —— 核心体验,强烈建议(工作量小收益大)

| # | 改进 | 现状问题 | 方案 | 工作量 |
|---|---|---|---|---|
| 1 | **多行粘贴确认** | 误粘贴多行命令到生产环境有风险 | 粘贴文本 >N 行/含换行时弹确认框(参考 SecureCRT) | 0.5d |
| 2 | **密码加密存储** | sessions.json 明文密码 | 用系统 DPAPI(node 库 keytar/自写 PowerShell DPAPI)加密 password 字段 | 1d |
| 3 | **会话分组/搜索** | 会话多了平铺难找 | 左侧栏加分组(文件夹)+ 顶部搜索框过滤 | 1d |
| 4 | **终端内搜索 Ctrl+F** | 长输出找不到关键字 | 加搜索条(高亮匹配 + 上下跳转,xterm 的 find addon) | 1d |
| 5 | **自动重连(可配置)** | 断线后要手动重连 | 会话配置加"自动重连 N 次/间隔",断线自动重试(服务端已有连接层,前端补逻辑) | 1d |

## 四、推荐实施顺序

1. **第一批(P0,约 4-5 天)**: 多行粘贴确认 → 会话分组/搜索 → 终端搜索 → 自动重连 → 密码加密
2. **第二批(P1,约 8-10 天)**: 主题定制 → 拖拽上传 → 快捷命令 → SSH 隧道 → 跳板机 → 快捷键
3. **第三批(P2,按需)**: 分屏 → 串口增强 → 端口扫描 → 独立 exe

> 原则: 优先补"常用场景刚需"(多行粘贴/搜索/分组/重连),再做"专业场景" (隧道/跳板/断点续传),最后"锦上添花"。
